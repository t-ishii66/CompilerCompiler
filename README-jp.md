# スクラッチから作るコンパイラコンパイラ — C言語によるセルフホスティング・パーサジェネレータ

<sub>[English](README.md) | **日本語**</sub>

<img src="top.png" alt="Compiler Compiler" width="300">

## 概要
本プロジェクトは小さな**コンパイラコンパイラ**(別名**パーサジェネレータ**)です。
すなわち、**BNF風の文法定義**を読み込み、その文法に対応する**C言語のパーサ/コンパイラ**を出力するツールです。

<!-- SEO intro added by setup-github-pages; review and adjust -->

「**自作コンパイラ**をゼロから作ってみたい」「**字句解析**・**構文解析**・**コード生成**がどう繋がっているかを理解したい」「**セルフホスティング**や**ブートストラップ・コンパイラ**の仕組みを、小さくて本物の例で学びたい」 ── そんな人のための **教育用コンパイラコンパイラ** です。扱うテーマは **BNF風の文法定義**、**再帰下降パーサ**、**バックトラック**、**構文木の構築**、**C言語へのトランスパイル**、**x86-64 アセンブリ生成** など、**yacc**・**bison**・**ANTLR** の代替となる、外部依存なしの最小実装を題材にしています。

<!-- /SEO intro -->

精神的には **yacc**、**bison**、**ANTLR** といった古典的なツールに似ていますが、外部依存を一切持たず、C言語でゼロから構築されています。**コンパイラ構築**、**字句解析**、**構文駆動翻訳**の中心的なアイデアを実演する、最小限の教育的実装です。

コンパイラコンパイラとは「コンパイラを生成するコンパイラ」だと考えることができます。C言語で**再帰下降パーサ**を手書きする代わりに、コンパクトな記法で文法を記述すると、ツールがその文法を認識・処理するCコードを — **バックトラック**、**構文木の構築**、**コード生成** までを含めて — 出力してくれます。

## 自己言及の物語 — ブートストラップ・コンパイラ
このリポジトリが特別なのは、**自己言及的**(別名**セルフホスティング**)であるという点です。

1. ファイル `t0.def` は、コンパイラコンパイラ自身の文法を定義しています。
2. その定義から、対応する生成済みCソースを(手作業で)作ることができ、それは `t3.out.c` として保存されています。
3. `t3.out.c` をコンパイルすると、実行ファイル `ccgen` が得られます。
4. `ccgen` を `t0.def` に対して実行すると、新しいファイル `t4.out.c` が生成されます。
5. `t4.out.c` は `t3.out.c` と**ビット単位で同一**です。

ここが頭がクラクラするポイントです。文法 `t0.def` は**コンパイラコンパイラそのもの**を定義しており、生成されたコンパイラは自分自身のソースコードを再生成できるのです。

## 主要ファイル
- `t0.def` — *このコンパイラコンパイラ自身を記述する*文法定義。
- `t3.out.c` — `t0.def` に対応する手作りのC言語実装。
- `comcom.h` — 生成されたすべてのパーサが利用するランタイムライブラリ。


## 自己生成を再現する
以下のコマンドを実行すると、自己生成が動作する様子を確認できます。

```sh
gcc t3.out.c -Wno-pointer-sign -o ccgen
./ccgen t0.def t4.out.c
diff t3.out.c t4.out.c
# (差分なし)
```

`diff` で差分が表示されなければ、自己再生成に成功しています。

## なぜ面白いのか
- **セルフホスティング/ブートストラップ・コンパイラ:** 自分自身を定義するシステムは稀で興味深いものです — このコンパイラコンパイラは自身のソースコードを再生成できます。
- **教育的価値:** **形式文法**がどのようにして動作するプログラムになるかを実演しており、**コンパイラ設計**や**言語実装**の学習に最適です。
- **コンパクトさ:** ランタイム(`comcom.h`)は小さく、出力は単純で移植性の高いCコードです — lex、flex、yacc などへの依存はありません。
- **複数のバックエンド:** 同梱されているミニ言語は、ひとつの文法から **C言語へのトランスパイル**と **x86-64ネイティブコード生成**の両方をターゲットにできることを示します。

## 独自の文法で始める
新しい文法を定義し、そこからC言語パーサを生成することができます。例として、`1+2*3` のような中置記法の式を `1 2 3 * +` のような後置記法に変換する **逆ポーランド記法(RPN)変換器**を作ってみましょう。

1. 文法ファイル `rpn.def` を書きます。
2. C言語パーサを生成します。

```sh
./ccgen rpn.def rpn.c
gcc rpn.c -Wno-pointer-sign -o rpn
```

3. 何らかの入力でテストします。

```sh
echo "1+2*3" | ./rpn
# 出力: 1 2 3 * +

echo "(1+2)*3" | ./rpn
# 出力: 1 2 + 3 *
```

## 文法の例: `rpn.def`
以下は、中置算術式を逆ポーランド記法に変換する完全な `rpn.def` です。重要な洞察は、`print()` と `call()` の順序を入れ替えることによって、演算子をオペランドの*後*に出力できるという点です。

```def
START(RPN)
RPN     : EXPR { call(1); print("\n"); }
;

EXPR    : TERM "+" EXPR     { call(1); print(" "); call(2); print(" +"); }
        | TERM "-" EXPR     { call(1); print(" "); call(2); print(" -"); }
        | TERM              { call(1); }
;

TERM    : FACTOR "*" TERM   { call(1); print(" "); call(2); print(" *"); }
        | FACTOR "/" TERM   { call(1); print(" "); call(2); print(" /"); }
        | FACTOR            { call(1); }
;

FACTOR  : "(" EXPR ")"      { call(1); }
        | NUMBER            { call(1); }
;

NUMBER  : DIGIT+NUMBER      { call(1); call(2); }
        | DIGIT             { call(1); }
;

DIGIT   : "0" { print("0"); }
        | "1" { print("1"); }
        | "2" { print("2"); }
        | "3" { print("3"); }
        | "4" { print("4"); }
        | "5" { print("5"); }
        | "6" { print("6"); }
        | "7" { print("7"); }
        | "8" { print("8"); }
        | "9" { print("9"); }
;
END
```

この文法は演算子の優先順位を自然に扱います。`*` と `/` は `TERM` のレベルで解析され、`+` と `-` は `EXPR` のレベルで解析されるため、`*` と `/` のほうが `+` と `-` よりも強く結合します。

## 注意点
- 出力の振る舞いに関する変更は、ほとんどの場合 `.def` ファイル側で行うべきです。
- ランタイムの機構(バックトラック、構文木、出力配管)は `comcom.h` に存在します。

## ミニ言語

本プロジェクトには、**mini** と呼ばれる完全なサンプル言語が含まれています。
これは、同じ文法に異なるバックエンドを持たせられることを実演します。
ひとつはC言語をターゲットとし、もうひとつは x86-64 アセンブリをターゲットとします。

### 文法(BNF風)

```
PROGRAM   := STATEMENT*

STATEMENT := "var" NAME
           | "set" NAME EXPR
           | "input" NAME
           | "out" EXPR
           | "if" COND BLOCK
           | "while" COND BLOCK

BLOCK     := STATEMENT* "end"

COND      := EXPR ">" EXPR
           | EXPR "<" EXPR
           | EXPR "=" EXPR

EXPR      := TERM "+" TERM
           | TERM "-" TERM
           | TERM "*" TERM
           | TERM "/" TERM
           | TERM

TERM      := NAME | NUMBER

NAME      := [a-z]+
NUMBER    := [0-9]+
```

### サンプルプログラム: フィボナッチ数列

```
var n
var i
var a
var b
var t

input n

set a 0
set b 1
set i 1

while i < n
set t a + b
set a b
set b t
set i i + 1
end

out b
```

### 二つのバックエンド

同じミニ言語に対して、二つのバックエンド実装が用意されています。

| 定義ファイル | ターゲット | 種別 |
|-----------------|--------|------|
| `mini.def` | C言語ソースコード | トランスパイラ |
| `mini-asm.def` | x86-64 アセンブリ | コンパイラ |

```
                        ┌─────────────┐
                        │  mini.def   │ → C言語トランスパイラ
                        └─────────────┘
                              ↑
┌──────────────┐        ┌───────────┐
│ program.mini │   →    │   ccgen   │  (コンパイラコンパイラ)
└──────────────┘        └───────────┘
                              ↓
                        ┌─────────────┐
                        │mini-asm.def │ → x86-64 コンパイラ
                        └─────────────┘
```

### mini.def を使う(C言語トランスパイラ)

```sh
# トランスパイラをビルド
./ccgen mini.def mini.c
gcc mini.c -Wno-pointer-sign -o mini

# mini を C にトランスパイルし、コンパイルして実行
./mini < program.mini > program.c
gcc program.c -o program
./program
```

### mini-asm.def を使う(x86-64 コンパイラ)

```sh
# コンパイラをビルド
./ccgen mini-asm.def mini-asm.c
gcc mini-asm.c -Wno-pointer-sign -o mini-asm

# アセンブリにコンパイルし、アセンブルして実行(Linux x86-64)
./mini-asm < program.mini > program.s
gcc program.s -o program -no-pie
./program
```

## 付録: ファイルリファレンス

### コアファイル

| ファイル | 説明 |
|------|-------------|
| `t0.def` | コンパイラコンパイラ自身の文法定義 |
| `t3.out.c` | コンパイラコンパイラの生成済みCソース |
| `comcom.h` | ランタイムライブラリ(構文解析、バックトラック、木構築) |

### ミニ言語のファイル

| ファイル | 説明 |
|------|-------------|
| `mini.def` | ミニ言語の文法 → C トランスパイラ |
| `mini.c` | 生成されたトランスパイラのソース(mini.def より) |
| `mini-asm.def` | ミニ言語の文法 → x86-64 コンパイラ |
| `mini-asm.c` | 生成されたコンパイラのソース(mini-asm.def より) |
| `program.mini` | サンプルプログラム(フィボナッチ計算機) |

### その他のサンプル

| ファイル | 説明 |
|------|-------------|
| `rpn.def` | 中置記法から逆ポーランド記法への変換器(文法) |
| `rpn.c` | 生成された RPN 変換器のソース(rpn.def より) |

### ビルド手順まとめ

```sh
# コンパイラコンパイラをビルド
gcc t3.out.c -Wno-pointer-sign -o ccgen

# 自己再生成を検証
./ccgen t0.def t4.out.c && diff t3.out.c t4.out.c

# ミニ言語トランスパイラをビルド
./ccgen mini.def mini.c && gcc mini.c -Wno-pointer-sign -o mini

# ミニ言語 x86-64 コンパイラをビルド
./ccgen mini-asm.def mini-asm.c && gcc mini-asm.c -Wno-pointer-sign -o mini-asm
```
